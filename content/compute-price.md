title: "Price of Compute"
description: >-
  Daily reference prices for public cloud CPU and GPU compute, created for personal
  use to guide hardware purchases. The entire analysis was done using ChatGPT-6
  Astra, which obtained the data online and implemented the fits. Multiple models
  were considered; I ended up using a multiplicative model for CPUs and a linear
  bandwidth model for GPUs, as they provided the best balance between simplicity
  and predictive power. The data, plots, and methodology are all open access.
